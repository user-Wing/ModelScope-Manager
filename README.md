# ModelScope Manager 1.0.8

Windows 桌面端 ModelScope 仓库资源管理器，基于 Python / PySide6 实现，使用官方 `modelscope-hub` SDK。

ModelScope（魔搭）是面向开发者的无限空间模型/数据集分享存储。本工具把官方 CLI/SDK 的仓库操作图形化：浏览、上传、下载、搜索、备份、图床与 WebDAV 挂载，一站式管理你的全部仓库。

## 特性

- **仓库资源管理**：左侧账户树 + 右侧资源管理器视图，拖拽即上传，右键即下载 / 复制直链 / 打标签；也可用「从链接导入文件」把 HTTP(S) 资源先下载到临时目录再上传到当前仓库目录
- **多账户**：Token 账户 + Edge WebView2 网页登录账户 + 只读 Public 公共池，三类来源同窗管理
- **全盘秒搜**：Everything 风格搜索（`path:` `name:` `ext:` `type:` 与通配符），直查本地索引
- **高速下载**：内置 aria2，断点续传、分段下载、暂停/恢复、SHA-256 校验
- **完整文件操作**：上传、下载、删除、移动、重命名（账户差异见「平台限制」）
- **备份与保险箱**：增量时间戳 / 同路径覆盖两种模式，可反向同步回本地
- **图床**：拖入或 Ctrl+V 粘贴即传，可按 AWJimage 默认预设转为 AVIF 后上传，自动生成公有 / 私有直链
- **WebDAV 网关**：纯本地实现，AList V3 免 Docker 直接挂载
- **Windows 直挂**：可按需启用 WebClient 并映射本机 WebDAV 根目录，无需 AList
- **传输恢复与历史**：退出保留下载断点和未完成队列，历史记录长期保存源、目标、结果、耗时与完成时间
- **媒体预览**：递归缩略图，外部播放器直链播放
- **插件下载**：设置页统一管理 PotPlayer、FFmpeg 等可选组件；下载包经固定大小与 SHA-256 校验后再解压安装
- **关于页**：左侧「关于」使用 Markdown 展示当前更新日志、第三方开源库引用和支持者列表
- **资源监控**：实时显示本进程 CPU、内存与显存，支持后台空闲时自动释放工作集
- **安全**：默认使用 DPAPI 设备绑定加密；实验栏目可在风险验证后切换为明文保存或关闭跨设备销毁
- **中英双语**：界面语言即时切换，无需重启

## 安装与运行

**便携包**（推荐）：从 [GitHub Release 1.0.8](https://github.com/user-Wing/ModelScope-Manager/releases/tag/1.0.8) 下载 `1.0.8.7z`。构建包内含 Python 运行时与全部依赖，无需安装任何环境。

ModelScope 镜像位于 [ARXChem/Software-List](https://modelscope.cn/datasets/ARXChem/Software-List/files) 的 `ModelScope-Manager/` 目录，也是软件内置更新器的数据源。

**源码运行**（Python 3.12）：

```powershell
py -3.12 main.py
```

依赖：`PySide6`、`PySide6-Fluent-Widgets`、`pywebview`、`modelscope-hub`、`requests`；网页登录需要系统 Microsoft Edge WebView2 Runtime。

可选 AVIF 预转换需要 FFmpeg。推荐在「设置 → 插件下载」安装内置 FFmpeg 插件，软件会放到 `embedded-tools/ffmpeg/ffmpeg.exe` 并由图床自动优先调用；也兼容系统 `PATH` 中的 FFmpeg。缺失时原图上传仍可使用。

## 快速上手

1. 左侧「设置」→ 添加 ModelScope 访问 Token（自动验证用户名，设备绑定加密保存）
2. 返回「资源管理」，展开「账户 → 模型/数据集」选择仓库
3. 把本地文件 / 文件夹拖到右侧任意目录 → 立即上传
4. 右键远端文件 → 下载 / 复制直链 / 标签 / 外部播放器
5. 「资源搜索」粘贴任意公开仓库链接即可浏览（无需 Token）

## 平台限制（先读）

ModelScope 官方**访问令牌不允许删除文件**，因此：

| 操作 | Token 账户 | 网页登录账户 | Public |
|---|---|---|---|
| 读取 / 下载 / 上传 | ✅ | ✅ | ✅ 只读 |
| 删除 / 移动 / 重命名 | ❌（提示走网页登录） | ✅ | ❌ |

- 删除由独立 Edge WebView2 私密登录会话执行，批量 100 文件/次提交，失败自动回退逐项
- 移动 / 重命名 = 先传后删，任一步失败旧文件全部保留
- 上传始终使用对目标仓库有权访问的 Token 账户

## 使用要点

**搜索**：空格分隔多条件 AND 匹配，支持 `path:` `name:` `ext:` `type:`、引号短语、`*` / `?` 通配符。查询在后台执行并分批显示大量结果；名称、类型、大小、仓库和路径均可点击表头排序。

**上传**：在资源管理器进入目标目录后点击「上传文件」或「上传文件夹」，也可把本地项目拖到顶部路径栏或文件夹。右上角「从链接导入文件」支持一行一个 `http://` / `https://` 链接，文件先进入本机临时目录，再用当前仓库对应的 Token 账户上传到当前目录，任务结束后临时文件自动清理；大文件会同时占用下载与上传时间，因此界面会提示谨慎使用。任务会进入传输列表；低于内置 SDK 100 GB 上限的单文件默认允许上传。

**下载**：勾选文件，或用 Shift / Ctrl 多选后点击「下载文件」或右键加入队列；未选择项目时下载按钮禁用。aria2 按文件大小自动分档分段（默认 1 / 32 / 64 段），支持限速与分时时段；文件夹下载还原目录结构。遇到本地同名文件可选择强制覆盖、恢复模式或不覆盖；恢复模式先按大小和远端 SHA-256 复用已完成文件，部分文件交给 aria2 断点续传，仅在内容不一致或无法验证完整文件时重新下载。下载与 SHA-256 校验分别显示实时百分比。

**传输列表**：上传 / 下载统一队列，显示总进度、速度、剩余时间；支持暂停 / 恢复 / 取消。关闭时未完成队列和 aria2 断点会写入便携配置，重启后点击开始即可继续；「历史记录」保存软件使用期间的传输结果。

**备份**：多个独立任务 = 本地文件夹 → 远端仓库。`增量备份（时间戳）` 每次建 `YYYYMMDD-HHMMSS` 目录；`同路径覆盖` 复用远端路径形成新版本（本地删除不回删远端）。可选「从云端同步到本地」。

**图床**：选择账户 / 仓库 / 路径，拖入或粘贴图片即上传到按年月划分的目录（随机短前缀防同名）。「选择图片」右侧可勾选「自动转换为 AVIF」；默认 q70 / speed 5，详细配置可调整质量、速度、色度、位深与元数据。转换器优先使用「设置 → 插件下载」安装到 `embedded-tools/ffmpeg/` 的 FFmpeg，其次使用系统 `PATH`。公开仓库自动复制 `/resolve/master/` 公有直链。

**WebDAV / AList 挂载**：设置页启动网关后，AList 添加存储：驱动 `WebDAV`、地址 `http://127.0.0.1:9867/dav/`、根路径 `/`、用户名密码见设置页。根目录含 `models/账户/仓库`、`datasets/账户/仓库` 与 `public/` 公共池；无 Token 时网关也能启动并提供公共池。文件下载会把 ModelScope 对象存储签名直链交给 AList，不由本地网关中转大文件内容。

左侧「WebDAV 映射」可以新建命名入口，把上述三个根节点下任意文件或目录重复挂载到自定义虚拟文件夹中。例如映射名为 `media` 时，可用 `http://localhost:9867/media` 直接访问组合后的目录。自定义映射默认只读；关闭只读需连续两次确认，实际写入仍受公开池只读和仓库账户权限限制。

不使用 AList 时，可在同一设置区选择盘符并点击 Windows 直挂。软件会先通过 UAC 校验 WebClient 系统 DLL、修复缺失的 `ServiceDll` 服务注册项，把 `BasicAuthLevel` 设置为 2，把默认 50 MB 单文件上限提高到 DWORD 最大值并扩展目录属性容量，重启服务后再用 Windows 网络提供程序映射当前 `/dav/` 根目录。为避免 HTTP Basic Auth 明文凭据进入网络，直挂只允许本机监听。Windows 内置 WebDAV 仍有约 4 GiB 的单文件结构性上限，更大的文件请使用 AList 直链挂载或软件内置下载。

公开资源输入框可粘贴仓库根链接，也可粘贴带 `/files/子目录` 或 `?path=子目录` 的链接；每个子目录会作为独立 Public 挂载。远端 `.7z`、`.zip`、`.tar`、`.iso`、`.gz`、`.xz` 可从右键菜单尝试 Range 浏览：7z/ZIP/ISO 使用稀疏首尾窗口，TAR 只读文件头并跨过成员内容；GZ/XZ 是单流格式，只展示压缩层元数据。AList 会收到同一对象存储直链与 Range 能力。

**媒体播放**：支持链接加载的外部播放器均可直链播放（已测试 PotPlayer、MPV 可用）。私有资源先下载再播放，Token 不进入播放器命令行。

**主题与界面**：主题设置独立成栏，支持亮色 / 暗色 / 跟随系统、多背景按页面编号映射、每页独立亮度、随机背景、背景自动取色或自定义取色；「关于」页皮肤编号为 `-1`，设置为 0，资源管理到 WebDAV 映射依次使用 1–6。切换亮/暗模式会把当前皮肤的页面亮度重置为 100%，避免沿用另一模式的暗化参数。`data/skin/` 下每个子目录是一套可切换皮肤；皮肤文件夹可直接导入，也可通过 ZIP/7z 导入，并可把当前皮肤导出为 ZIP。顶部和底部文字支持速度、流量、版本、CPU、内存与运行时间通配符；底部文字按实际内容和窗口宽度自动适配，在状态栏右侧从左到右显示，左侧保留给 AList、aria2 等临时状态。窗口顶部默认不再写死版本号。完整格式见 [skin.md](skin.md)。西文与中文字体、全局字号仍可实时切换。

**文件列表列**：详细信息模式固定保留名称、类型、大小；右键表头选择「选择列」，可另外显示 ModelScope 接口返回的最后修改时间、Git/LFS 存储方式、SHA-256 和 Blob ID。

**设置迁移**：设置页可把常规设置导出为 INI 并立即导入；皮肤、实验性功能、凭据和未完成传输队列不会写入导出文件。

**资源监控**：设置页每 2 秒显示本进程 CPU、工作集、私有内存及专用/共享显存。后台自动释放默认开启，只有无传输任务且工作集超过阈值时才执行；也可手动点击「立即释放内存」。

**软件更新**：设置页可开启启动后自动检查，或手动检查。软件从 `ARXChem/Software-List` 数据集的 `ModelScope-Manager/` 目录选择版本号最高的 7z 包，用内置 aria2-next 下载并校验、内置 7z 解压；确认重启后替换程序文件，`data/` 始终保留。

**实验性功能**：设置页最底部可启用明文凭据，或关闭跨设备自动销毁。二者均需先确认风险并完成随机四位数加法验证；任一选项开启后，窗口顶部会持续显示高风险测试模式提示。

## 数据与安全

全部数据收敛在程序目录 `data/`：

| 文件 | 内容 |
|---|---|
| `manager.sqlite3` | 账户元数据、加密 Token、仓库缓存、文件索引、目录大小 |
| `settings.ini` | 界面与功能设置 |
| `device.id` | 设备绑定标识 |
| `public_pools.json` | 已加载的公开仓库 |

`manager.sqlite3` 同时保存传输历史；待恢复队列保存在 `settings.ini`，认证 Token 不写入队列。自定义皮肤分别保存在 `data/skin/<皮肤目录>/`。

Token 使用系统级加密并与 `device.id` 绑定。把整个目录复制到其他电脑后，副本会生成新设备标识并**立即清除其中的 Token**，原机器不受影响。

## 开发

`main.py` 检测到便携 `runtime/Lib/site-packages` 时优先注入，避免误载其他 Qt 绑定的同名包。`app.py` 是兼容入口，页面构建与业务行为已按职责拆分；完整架构地图见 `project.md`。

## 常见问题

- **AList 挂载失败 `dial tcp ... connectex`**：网关未启动或地址不对。同机用 `127.0.0.1`；其他设备选局域网监听并放行防火墙。
- **WebDAV 端口被占用**：自动切换相邻端口，窗口顶部会提示实际端口。
- **文件夹大小不新**：大小来自本地索引，点右上角「更新索引」手动重建。
- **无法删除 / 移动 / 重命名**：Token 账户受平台限制，在「在线登录」列表添加网页会话后操作。
- **网页登录窗口无法打开**：安装或修复 Microsoft Edge WebView2 Runtime；便携包不再携带 QtWebEngine。
- **AVIF 预转换提示未找到 FFmpeg**：优先到「设置 → 插件下载」安装 FFmpeg；也可自行把兼容版本加入 `PATH` 或放到 `embedded-tools/ffmpeg/ffmpeg.exe`。取消勾选后可继续上传原图。
- **超大文件上传失败**：软件已默认允许低于 100 GB 的单文件；达到内置 SDK 上限或平台限制时会显示 SDK 返回的错误。
- **新建目录在仓库里看不到**：Git 仓库不保存空目录，首次上传内容后出现。
